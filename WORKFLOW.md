## STEP 0 — PROJECT SETUP

> AI မှ အောက်ပါ မေးခွန်းများ တစ်ခုချင်းစီ မေးရမည်။
> User ဖြေပြီးမှ STEP 1 သို့ ဆက်ရမည်။

```
Q1. PROJECT TITLE      : ဒီ series / video ရဲ့ အမည်ကဘာလဲ?

Q2. VISUAL STYLE       : အောက်ပါ style တွေထဲမှ ရွေးပါ —

    [A] CINEMA REALISTIC
        တကယ့်လူ၊ တကယ့်နေရာ၊ photorealistic
        ဥပမာ — သမိုင်းဝင်တိုက်ပွဲ၊ ချစ်ကြိုးဇာတ်လမ်း

    [B] 3D ANIMATION (Pixar/Disney style)
        Stylized 3D characters၊ vibrant colors
        ဥပမာ — ကလေးဇာတ်လမ်း၊ fantasy adventure

    [C] 2D ANIMATION (Anime / Cartoon style)
        Flat or semi-flat 2D၊ expressive characters
        ဥပမာ — action anime၊ comedy cartoon

    [D] PIXEL ART ANIMATION
        Retro pixel style၊ 8-bit or 16-bit feel
        ဥပမာ — game-style story၊ nostalgic adventure

    [E] DARK FANTASY REALISTIC
        Cinematic realistic + dramatic dark tones
        ဥပမာ — supernatural၊ mythology၊ horror-adjacent

    [F] CUSTOM — ကိုယ်တိုင် describe လုပ်မည်

Q3. GENRE              : ဇာတ်လမ်း genre ကဘာလဲ?
    (Action / Romance / Comedy / Drama / Fantasy / Historical / Horror)

Q4. ERA / SETTING      : ဘယ်ခေတ်၊ ဘယ်နေရာမှာ ဖြစ်တာလဲ?
    (ဥပမာ — မြန်မာ့ရှေးဟောင်းဘုရင်ခေတ် / ခေတ်သစ်မြို့ / မြူဆိုင်းတောအုပ်)

Q5. DIALOGUE LANGUAGE  : မြန်မာ / English / နှစ်ခုလုံး?

Q6. SUBTITLE LANGUAGE  : မြန်မာ / English / မလို?

Q7. STORY OUTLINE      : ဇာတ်လမ်း အကျဥ်းကို ပြောပြပါ —
    - ဇာတ်ကောင် အဓိက ဘယ်သူတွေ?
    - အဓိက conflict က ဘာ?
    - ဇာတ်လမ်း ဘယ်မှာ ဆုံးမည်?
```

> ✅ STEP 0 ပြီးရင် → **PHASE 1** အလိုအလျောက် စမည်

## PHASE 1 — SCRIPT (Episode 1)

> 🎯 User ၏ story outline ကို အခြေခံ၍ Episode 1 script ထုတ်မည်။
> ✅ User approve မဖြစ်ခင် Phase 2 မသွားရ။

### Script Rules

```
CLIP DURATION     : 8sec တစ်ခု (Veo fixed)
SCENE GROUPING    : ဆက်နေသော action တွေ → clip တစ်ခုတည်း ဖြစ်အောင်ပေါင်း
SHORT MOMENTS     : 3-4sec သာလိုသော scene → ဆက်နေသော clip နဲ့ ပေါင်းပြီး 8sec ဖြည့်
ACTION CONTINUITY : မြင်းပြေး/တိုက်ပွဲ/ပြေး = clip တစ်ခုတည်း — ပြတ်တောင်းပြတ်တောင်း မဖြစ်ရ
DIALOGUE          : Minimal — action/visual storytelling ဦးစားပေး
EPISODE LENGTH    : Episode 1 = max ~2 min (15 clips အများဆုံး)
CLIFFHANGER       : Episode 1 သည် Episode 2 ကို စောင့်ချင်အောင် ဆုံးရမည်
```

### Script Format

```
=== EPISODE [N] | [ခေါင်းစဥ်] ===
STYLE         : [Selected style from STEP 0]
TOTAL CLIPS   : [N]
EST. RUNTIME  : ~[X] min [Y] sec

--- CLIP [N] ---
SCENES COMBINED : [merged scenes / standalone]
LOCATION        : [ENV_LocationName]
CHARACTERS      : [CHAR_Name1, CHAR_Name2]
SHOT            : [Wide / Medium / Close-up / Drone / Rotate / POV / Tracking]
CAMERA MOVE     : [Static / Push-in / Pull-back / Orbit / Drone descend / Lateral track]
ACTION SEQUENCE : [ဆက်တိုက် action ဖော်ပြ — start မှ end အထိ]
DURATION        : 8sec

DIALOGUE (if any):
[CHAR_Name]: "[ဘာသာစကား]"
SUBTITLE      : "[Subtitle language]"

FLOW NOTE       : [ရှေ့ clip မှ ဘယ်လိုဆက်သလဲ / နောက် clip ဘာနဲ့ ဆက်မည်]
SOUND CUE       : [ambient / music / silence]
---
```

### Camera Shot Guide

```
ESTABLISHING    → Drone wide descend — နေရာကြီးကျယ်မှု ပြ
INTRO CHARACTER → Medium push-in — ဇာတ်ကောင် ပထမဆုံးပေါ်လာချိန်
EMOTIONAL REVEAL→ Extreme close-up မျက်လုံး — ဉာဏ်ထွက် / ဆုံးဖြတ်ချက်
DIALOGUE        → Medium two-shot သို့မဟုတ် alternating close-ups
ACTION / BATTLE → Wide lateral tracking — motion အပြည့်မြင်ရ
IMPACT MOMENT   → Extreme close-up → freeze → slow-mo
ENDING          → Medium wide — fade to black သို့မဟုတ် freeze frame
```

> 🔁 Script ပြီးရင် AI မှမေးမည် —
> **"Script ကြည့်ပြီးပါပြီ။ ကြိုက်ပါသလား? ✅ ဆက်မလား ❌ ပြင်မလား?"**
> ✅ Approve မဖြစ်ခင် Phase 2 မသွားရ။

## PHASE 5 — VEO VIDEO PROMPTS

> 🎯 Locked scene images → Veo 8sec video prompts

### Continuity Rules

```
CONTINUE FROM   : ရှေ့ clip ၏ ending action/position ကို ဖော်ပြရမည်
LEADS INTO      : နောက် clip ၏ starting action ကို ဖော်ပြရမည်
ACTION COMPLETE : Battle/chase/impact = clip တစ်ခုထဲ ပြီးစီးရမည်
CAMERA SMOOTH   : Abrupt jump cut မသုံးရ — motion smooth ဖြစ်ရမည်
```

### Video Prompt Format

```
--- VIDEO CLIP [N] ---
SOURCE IMAGE    : Clip_[N]_composition
DURATION        : 8sec (Veo fixed)
CAMERA MOTION   : [static / slow push-in / drone descend / lateral track / 360 orbit]
CONTINUE FROM   : [ရှေ့ clip ending — e.g. "character mid-stride walking forward"]
LEADS INTO      : [နောက် clip start — e.g. "door already opening"]

VIDEO PROMPT:
"[Style] 8-second video clip,
[CAMERA MOTION] — [describe motion path],
ENVIRONMENT: [ENV_LocationName — ambient motion details],
ACTION: [full action sequence start to end — no internal cuts],
[CHAR_Name1 — locked outfit, motion, expression],
[CHAR_Name2 if present — reaction/counter-action],
DIALOGUE: [CHAR_Name mouth-syncs] '[line]',
SOUND: [ambient sounds],
MUSIC: [BGM mood cue],
mood: [emotional tone],
seamless continuation from previous clip,
[style rendering keywords], 8K"
```

### Transition Guide

```
[TRANSITION: 0.3s crossfade]  ← normal scene change
[TRANSITION: hard cut]        ← impact / shock moment
[TRANSITION: slow dissolve]   ← time passing / emotional shift
[TRANSITION: fade to black]   ← episode ending
[TRANSITION: iris close]      ← comedy / stylized ending
```

### BGM Mood Cues

```
EPIC / BATTLE BUILDUP  → rising orchestra, drums accelerating
PEAK BATTLE ACTION     → full orchestra, intense percussion
CHARACTER INTRO        → solo instrument theme, memorable melody
EMOTIONAL / SAD        → slow strings or piano, fading
VICTORY / RESOLUTION   → triumphant brass, full ensemble
MYSTERY / SUSPENSE     → low drone, sparse notes, silence
COMEDY / LIGHT         → bouncy woodwinds, playful rhythm
ROMANCE                → soft strings, gentle melody
```

> 🔁 Clip prompts ထုတ်ပြီးရင် —
> **"Video prompts အဆင်သင့်ပါပြီ။ Veo တွင် generate လုပ်ပါ။"**
