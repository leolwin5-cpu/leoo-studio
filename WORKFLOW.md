## PHASE 1 — SCRIPT (Episode 1)

> 🎯 Story outline မှ Episode 1 script ထုတ်မည်
> ✅ Approve မဖြစ်ခင် Phase 2 မသွားရ

### Script Rules
```
CLIP DURATION     : 8sec တစ်ခု
SCENE GROUPING    : ဆက်နေသော action → clip တစ်ခုတည်းပေါင်း
SHORT MOMENTS     : 3-4sec scene → ဆက်နေသော clip နဲ့ ပေါင်း 8sec ဖြည့်
ACTION CONTINUITY : Battle/chase = clip တစ်ခုတည်း — ပြတ်တောင်းပြတ်တောင်းမဖြစ်ရ
DIALOGUE          : Minimal — visual storytelling ဦးစားပေး
EPISODE LENGTH    : max ~2 min (15 clips အများဆုံး)
CLIFFHANGER       : Ep1 = Episode 2 ကို စောင့်ချင်အောင် ဆုံးရမည်
```

### Script Format
```
=== EPISODE [N] | [ခေါင်းစဥ်] ===
STYLE        : [chosen style]
IMAGE TOOL   : [chosen tool]
VIDEO TOOL   : [chosen tool]
TOTAL CLIPS  : [N]
EST. RUNTIME : ~[X] min

--- CLIP [N] ---
SCENES COMBINED : [merged / standalone]
LOCATION        : [ENV_Name]
CHARACTERS      : [CHAR_Name1, CHAR_Name2]
SHOT            : [Wide/Medium/Close-up/Drone/POV/Tracking]
CAMERA MOVE     : [Static/Push-in/Pull-back/Orbit/Drone descend/Lateral]
ACTION SEQUENCE : [start မှ end အထိ ဆက်တိုက်ဖော်ပြ]
DURATION        : 8sec

DIALOGUE (if any):
[CHAR]: "[line]"
SUBTITLE: "[translation]"

BGM CUE  : [mood music — e.g. dramatic orchestra / slow piano / silence]
SFX CUE  : [action sounds — e.g. sword clash, horse hooves, crowd murmur]
MIX      : Dialogue 100% / SFX 70% / BGM 25%
           → Dialogue ရှိချိန် BGM နှိမ့်ထား (ducking)
           → Action ဖြစ်ချိန် SFX ထင်ရှားအောင်

FLOW NOTE  : [ရှေ့ clip မှ ဆက် / နောက် clip သို့ ဘာနဲ့သွား]
---
```

> 📌 **SOUND NOTE:**
> Phase 5 video prompt ထဲ BGM + SFX တစ်ခါတည်း ထည့်နိုင်သည် (Veo 3 / Kling)
> BGM continuity အတွက် Phase 5.5 CapCut မှာ episode-wide BGM track ထပ်ခံပါ

### Camera Guide
```
ESTABLISHING     → Drone wide descend
CHARACTER INTRO  → Medium push-in
EMOTIONAL REVEAL → Extreme close-up မျက်လုံး
DIALOGUE         → Medium two-shot / alternating close-ups
ACTION / BATTLE  → Wide lateral tracking
IMPACT           → Extreme close-up → freeze → slow-mo
ENDING           → Medium wide → fade black / freeze frame
```

## PHASE 5.5 — POST PRODUCTION (CapCut)

> 🎯 Generated clips တွေကို CapCut မှာ assembly လုပ်မည်

```
STEP 1 — IMPORT
  → Generated video clips အားလုံး CapCut သို့ import လုပ်ပါ
  → Clip order = Phase 4 script အတိုင်း စီပါ

STEP 2 — TRANSITIONS
  → Clip တစ်ခုနဲ့တစ်ခုကြား Phase 5 မှ သတ်မှတ်ထားသော
    transition type အတိုင်း ထည့်ပါ
    [CROSSFADE 0.3s] / [HARD CUT] / [SLOW DISSOLVE] / [FADE TO BLACK]

STEP 3 — SUBTITLE (Phase 1.5 မှာ မြန်မာ ရွေးထားလျှင်)
  → Video generate လုပ်ချိန်မှာ subtitle burn မပါသေးလျှင်
  → CapCut Auto Caption သုံး → English subtitle ထည့်ပါ
  → Font: Bold White, Position: Bottom Center

STEP 4 — BGM
  → Phase 5 BGM cue အတိုင်း CapCut sound library မှ ရှာပါ
  → Dialogue volume: 100% / BGM volume: 20-30%

STEP 5 — EXPORT
  → Resolution : 1080p (16:9) / 1080x1920 (9:16) / 1080x1080 (1:1)
  → Frame rate  : 24fps (cinematic) / 30fps (standard)
  → Format      : MP4
```
